# AI Orchestration Framework (AOF) v1.0 LTS

This directory is the canonical packaged release set for **AOF v1.0 LTS**.

Start with:
1. `release/AOF-v1.0-LTS-Declaration.md`
2. `specification/AOF-v1.0-Framework-Specification.md`
3. `release/AOF-v1.0-LTS-Release-Manifest.json`
4. `SHA256SUMS.txt`

Machine-readable schemas, the Executable Conformance Suite, Reference Implementation, and the
complete LTS audit are distributed as immutable ZIP artifacts inside their respective directories.

The frozen specification remains the normative semantic authority. JSON Schema is the canonical
machine-readable structural contract; schema validity alone does not establish AOF conformance.
